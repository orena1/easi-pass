# Versions this pipeline has actually been run against, as opposed to versions
# that merely satisfy the ranges in pyproject.toml. Input to requirements.txt,
# not something you install directly.
#
# PyTorch: 2.5.1 is the version the old conda environment.yml installed
# (`pytorch::pytorch=2.5`), so it is the one every result to date was produced
# with. The PyPI wheel bundles CUDA 12.4 and needs an NVIDIA driver of 525 or
# newer. Two reasons to raise it, both requiring you to regenerate
# requirements.txt: a GPU newer than the CUDA 12.4 wheels support (anything past
# Hopper), or a security fix. pyproject.toml allows the whole 2.x line, so
# raising it here is all that is needed.
torch==2.5.1
